# Cardora Design System — Sync Notes

## Setup facts

- **Shape**: package (no Storybook)
- **Source**: `frontend/src/shared/components/` inside a Next.js 16 app — NOT a standalone package
- **Node modules**: `frontend/node_modules` (package is at `frontend/`)
- **Tailwind**: v4 via `@import "tailwindcss"` — cannot use globals.css directly as cssEntry; use `frontend/src/shared/ds-styles.css` (pre-built or manually authored)
- **Fonts**: Manrope, Geist, Geist Mono loaded via `next/font/google` (Next.js only). For the DS bundle, Manrope is imported via Google Fonts CDN in `ds-styles.css`. Marked as `runtimeFontPrefixes` to suppress FONT_MISSING.
- **ThemeProvider**: Custom React context in `frontend/src/shared/contexts/ThemeContext.tsx`. Included via `extraEntries`. Required by `ThemeToggle` (which calls `useTheme()`). Set as `cfg.provider`.
- **Path alias**: `@/*` → `frontend/src/*` (see `frontend/tsconfig.json`). The `--tsconfig frontend/tsconfig.json` flag is needed for alias resolution.

## Skipped components

- **Sidebar** — imports `next/link` and `next/image`; cannot bundle outside Next.js
- **Footer** — imports `next/link`
- **MobileTopBar** — imports `next/link`

## CSS strategy

`ds-styles.css` is a hand-authored CSS file (NOT processed by Tailwind) that includes:
1. Google Fonts CDN import for Manrope
2. All CSS custom property tokens from `globals.css`
3. Tailwind utility classes generated by running `@tailwindcss/cli` on the project

If Tailwind build fails: ds-styles.css still provides the design tokens; components will render with correct color/spacing tokens but Tailwind utility classes may be absent.

## Known render warns

- **ThemeToggle** — no authored preview; uses floor card. Root cause: `ThemeProvider` has a `mounted` guard (`if (!mounted) return <>{children}</>`) that renders children WITHOUT the context on the first render tick. `useTheme()` throws in that state. Fix would require removing the mounting guard in `ThemeContext.tsx` or splitting ThemeProvider into a mount-safe wrapper.

## Re-sync risks

- **Tailwind utility classes**: If components start using new utility classes and `ds-styles.css` isn't rebuilt, previews may be partially unstyled.
- **ThemeProvider**: The provider wrapper uses `useEffect` + `localStorage` which run fine in headless Chrome but depend on browser APIs. If previews show unstyled output, confirm the ThemeProvider isn't blocking renders.
- **`use client` directives**: All components have `'use client'` which is a Next.js directive — esbuild strips it (it's just a string literal comment), so this should be harmless.
- **`next/font` references**: Layout.tsx uses `next/font/google` — but Layout.tsx is not synced. Only shared/components/ is synced. Monitor if any component inadvertently imports from `next/`.
